# 💰 Personal Budget Tracker (Java Showcase)

A console-based financial management application developed in Java. It allows users to track dynamic incomes, log categorized expenses, and map balances against active financial savings targets.

### 🛠️ Core Technical Architecture
- **Data Structuring:** Utilizes Java Collections framework (`HashMap`) for dynamic key-value financial indexing.
- **Dynamic Math Engine:** Implements runtime arithmetic reductions utilizing iterative map entries.
- **Robust Exception Parsing:** Implements controlled stream consumption (`Scanner`) inside operational control loops.
